# 📐 Geometric Object Area & Perimeter Calculator  

![Version](https://img.shields.io/badge/version-1.0.0-green.svg)  
![Java](https://img.shields.io/badge/Language-Java-orange.svg)  

The **Geometric Object Area & Perimeter Calculator** is a **Java-based** graphical user interface (GUI) application designed to calculate the area and perimeter of geometric shapes such as **circles, rectangles, and squares**.  
This project was developed as part of the **Object-Oriented Programming (OOP)** course at **Assiut National University** under the supervision of **Prof. Dr. Maged Askar**.  

---

## 🚀 Features  

### Shape Selection  
- A **combo box** allows users to select the geometric shape (circle, rectangle, or square).  

### Input Fields  
- **Text fields** for entering required dimensions:  
  - **Circle**: Radius.  
  - **Rectangle**: Width and height.  
  - **Square**: Side length.  

### Calculation & Display  
- A **Calculate** button computes the area and perimeter of the selected shape.  
- Results are displayed in a **label**.  

### Validation  
- Ensures all input values are valid before performing calculations.  

### Inheritance  
- The **Square** class inherits from the **Rectangle** class, demonstrating OOP principles.  

---

## 🛠️ How It Works  

1. **Select Shape**: Choose a shape from the combo box.  
2. **Enter Dimensions**: Input the required dimensions in the provided text fields.  
3. **Calculate**: Click the **Calculate** button to compute the area and perimeter.  
4. **View Results**: The results are displayed in the designated label.  

---

## 📂 Project Structure  

### Classes  
- **GeometricObject**: Base class for geometric shapes.  
- **Circle**: Extends `GeometricObject` to handle circle-specific calculations.  
- **Rectangle**: Extends `GeometricObject` to handle rectangle-specific calculations.  
- **Square**: Inherits from `Rectangle` to handle square-specific calculations.  

### GUI Components  
- **Combo Box**: For shape selection.  
- **Text Fields**: For dimension input.  
- **Button**: Triggers the calculation.  
- **Label**: Displays the results.
